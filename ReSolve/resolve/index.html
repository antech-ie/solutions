Recovered litres × (solvent cost + waste cost) = gross annual value

A simple QC principle, applied with control.

ReSolve separates reusable baseline mobile phase from analyte-containing peak fractions after detection. It is not waste-solvent purification; it is controlled reuse of suitable mobile phase within the QC process.

ReSolve

Add controlled mobile-phase reuse to the HPLC systems already in place.

ReSolve connects downstream of the detector and controls whether suitable baseline mobile phase is returned for reuse or directed to waste.

✓Works with suitable isocratic QC workflows across existing HPLC brands.
✓Records recovered and waste volumes for operational review.

System path

Reuse what is clean. Discard what is not.

When the detector sees baseline flow, suitable mobile phase can return to the reservoir. When it sees an analyte peak, that fraction is sent to waste.
